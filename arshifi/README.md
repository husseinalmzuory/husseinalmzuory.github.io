# أرشيفي
موقع عربي شخصي يعمل على GitHub Pages ويحفظ البيانات والمرفقات في Google Drive بصلاحية drive.file فقط.

## الربط
1. أنشئ مشروع Google Cloud وفعّل Google Drive API.
2. أعد Google Auth Platform، ثم OAuth Client من نوع Web application.
3. أضف الأصل https://husseinalmzuory.github.io إلى Authorized JavaScript origins.
4. إذا كان التطبيق External/Testing أضف بريد الحساب الجامعي إلى Test users.
5. افتح إعدادات الربط في الموقع وأدخل Client ID فقط. لا تستخدم Client Secret.
6. اضغط ربط Google Drive ووافق بالحساب المقصود. قد يمنع مسؤول الجامعة التطبيقات الخارجية.

## التخزين والخصوصية
- لا يُرفع أي مستند شخصي إلى GitHub. الواجهة عامة؛ البيانات لا تظهر إلا بعد تفويض حساب Drive.
- رمز الوصول في ذاكرة الصفحة فقط وينتهي تلقائيًا. يلزم تجديد الربط عند انتهاء الجلسة.
- Client ID العام محفوظ محليًا لكل متصفح. استخدم نفس Client ID على كل الأجهزة؛ تغيير تطبيق OAuth قد يمنع اكتشاف ملفات التطبيق السابق.
- مجلد خاص باسم أرشيفي — الأرشيف الشخصي؛ ملفات السجلات JSON والمرفقات الأصلية محفوظة فيه. العرض بحسب العام يتم من فهرس السجلات، وليس بمجلدات فعلية للأعوام.
- كل سجل ملف مستقل لتجنب فقد سجلات أخرى عند الإضافة من جهازين. تحرير السجل نفسه على جهازين يتبع آخر حفظ.
- السلة حذف منطقي داخل السجل، ويمكن استرجاعه. لا توجد عملية حذف نهائي في هذه النسخة.
- المرفقات التي أزيلت من سجل أو رُفعت قبل فشل حفظ السجل تبقى في Drive احتياطًا؛ لا يحذف التطبيق الأصل تلقائيًا.
- التصنيفات تُكتب بحرية وتظهر تلقائيًا عند استخدامها. العام الفارغ الجديد يصبح دائمًا عبر الأجهزة عند حفظ سجل فيه.
- النسخ الاحتياطي ZIP يشمل جميع السجلات والمرفقات بما فيها سلة الأرشيف؛ أبقِ الصفحة مفتوحة. الأرشيف الكبير قد يتطلب ذاكرة كبيرة. استيراد النسخة غير متاح حاليًا؛ الفهرس والملفات متاحان للاستعادة اليدوية.
- تعتمد واجهة Google على accounts.google.com، وتستخدم النسخة الاحتياطية JSZip من CDN.

## التحقق
فحص صياغة JavaScript، ومعاينة الواجهة والتنقل والأعوام وإعدادات الربط. اختبار Google Drive الفعلي ينتظر إعداد OAuth وموافقة الحساب الجامعي؛ لا تدّعي النسخة أنها مرتبطة مسبقًا.
